## 一、出栈序列

用于计算所有出栈序列的种类

### 栈的 “混洗”与出栈序列的合法性

栈的 **混洗** 问题通常考察的是，给定一个入栈顺序，能否产生一个特定的出栈顺序。通过栈的**后进先出（LIFO）\**特性，我们可以模拟栈的操作，来判断某个出栈序列是否合法。***

1. 从左到右遍历出栈序列。

2. 用一个栈来模拟入栈和出栈操作。

3. 对于每一个元素，如果当前栈顶元素和出栈序列的当前元素相等，则弹出栈顶元素并继续检查下一个出栈元素。

4. 如果当前栈顶元素不等于出栈序列的当前元素，则继续将入栈序列的下一个元素压入栈中，直到栈顶元素和当前出栈元素相等。

5. 如果在此过程中遇到栈无法弹出正确的元素（即栈顶元素始终不等于出栈序列的当前元素），说明出栈序列不合法。

```cpp
int main() {
    ios::sync_with_stdio(false);
	cin.tie(NULL); 
	cout.tie(NULL);
	cout << fixed << setprecision(6);
	
    int n; cin >> n;
    vector<int> a(n);
	int p = 1;
    for(int i = 0; i < n; ++i) {
	    cin >> a[i];
    }
	stack<int> x;
	for(int i = 0 ; i < n ;) {
		if(x.empty() || x.top() < a[i])  {
			x.push(p);
			p++;
			// cout << p << endl;
		} else if( x.top() == a[i]) {
			x.pop();
			// cout << i << endl;
			i++;
		} else if(x.top() > a[i]) {
			cout << "NO";
			return 0;
		}
	}
	cout << "YES";
	return 0;
}
```

***更进一步，栈的出栈序列的\**数量**可以通过递推方法（卡特兰数）来求解。接下来我将从基础的递推过程到卡特兰数公式给你详细讲解。

#### 1.  n = 1

- **n = 0 时**，出栈序列为空，只有1种可能：
  - 出栈序列：`{}`。
- **n = 1 时**，只有1个元素，出栈序列必然只有1种：
  - 出栈序列：`{1}`。

#### 2. n = 2 时 

假设进栈顺序为 `1, 2`。根据栈的特性，出栈序列的合法性有两种可能：

- **出栈序列中 1 在首位**：此时 `1` 出栈，剩下的是 `2`，此时可得到出栈序列 `{1, 2}`。此时左侧没有元素，右侧有 `m0 * m1 = 1` 种可能（即 `{1, 2}`）。
- **出栈序列中 1 在末位**：此时 `1` 要等到 `2` 出栈后才能出栈，出栈序列为 `{2, 1}`。此时左侧有 `m1` 个元素，右侧有 `m0` 个元素，所以可能性是 `m1 * m0 = 1` 种。

总的来说，`n = 2` 时，出栈序列的总数是 `m0 * m1 + m1 * m0 = 2` 种。

#### 3. n = 3 时

进栈顺序为 `1, 2, 3`，我们可以根据 `1` 在不同位置的情况进行推导：

- **出栈序列中 1 在首位**：此时 `1` 出栈，剩下 `2, 3`，有 `m0 * m2 = 2` 种可能。可能的出栈序列有 `{1, 2, 3}` 和 `{1, 3, 2}`。
- **出栈序列中 1 在第二位**：此时 `1` 被夹在中间，`2` 出栈后，`3` 出栈，剩下 `m1 * m1 = 1` 种可能。出栈序列为 `{2, 1, 3}`。
- **出栈序列中 1 在末位**：此时 `2` 和 `3` 先出栈，`1` 最后出栈，剩下 `m2 * m0 = 2` 种可能。可能的出栈序列有 `{2, 3, 1}` 和 `{3, 2, 1}`。

总的来说，`n = 3` 时，出栈序列的总数是 `m0 * m2 + m1 * m1 + m2 * m0 = 2 + 1 + 2 = 5` 种。

#### 4. n = 4 时

进栈顺序为 `1, 2, 3, 4`，根据 `1` 在不同位置的情况进行推导：

- **出栈序列中 1 在首位**：此时 `1` 出栈，剩下的是 `2, 3, 4`，有 `m0 * m3 = 5` 种可能。可能的出栈序列有 `{1, 2, 3, 4}`, `{1, 2, 4, 3}`, `{1, 3, 2, 4}`, `{1, 3, 4, 2}`, `{1, 4, 3, 2}`。
- **出栈序列中 1 在第二位**：此时 `1` 被夹在中间，剩下 `2` 和 `3, 4`，有 `m1 * m2 = 2` 种可能。可能的出栈序列有 `{2, 1, 3, 4}` 和 `{2, 1, 4, 3}`。
- **出栈序列中 1 在第三位**：此时 `2` 和 `3` 先出栈，`1` 在中间，剩下 `4`，有 `m2 * m1 = 2` 种可能。可能的出栈序列有 `{2, 3, 1, 4}` 和 `{3, 2, 1, 4}`。
- **出栈序列中 1 在第四位**：此时 `2, 3, 4` 先出栈，`1` 最后出栈，剩下 `m3 * m0 = 5` 种可能。可能的出栈序列有 `{2, 3, 4, 1}`, `{2, 4, 3, 1}`, `{3, 2, 4, 1}`, `{3, 4, 2, 1}`, `{4, 3, 2, 1}`。

总的来说，`n = 4` 时，出栈序列的总数是 `m0 * m3 + m1 * m2 + m2 * m1 + m3 * m0 = 5 + 2 + 2 + 5 = 14` 种。

> 上文中 $m_i$ 即为大小为 $i$ 的栈的出栈序列可能性大小，即下文卡特兰数

## 二、卡特兰数（Catalan Number）

对于一般情形，给定 `n` 个元素，进栈顺序为 `1, 2, 3, ..., n`，出栈序列的合法性总数可以由**卡特兰数**公式计算。卡特兰数 `C_n` 的递推公式如下：

$C_n = \sum_{i=0}^{n-1} C_i \times C_{n-1-i}$

其中：

- `C_0 = 1`，即没有元素时的出栈序列只有1种（空序列）。
- `C_n` 表示有 `n` 个元素的合法出栈序列的数量。

卡特兰数的推导过程可以从**递归公式**出发，并最终得到**显式公式**。我将从最初的数量开始，通过递推推导并最终给出卡特兰数的公式。这里会详细说明每个步骤和公式背后的推导过程。

### 一、卡特兰数的递推公式

卡特兰数 $C_n$ 是用于计数一些组合问题的数量，特别是树形结构、有效括号序列等问题。最早的卡特兰数定义是递推公式：

$$
C_n = \sum_{i=0}^{n-1} C_i \times C_{n-1-i}
$$

其中：

* $C_0 = 1$ 是基数，即没有元素时有 1 种可能。
* 递推公式的意义：若我们有 $n$ 个元素，假设我们将一个元素固定在某个位置，然后将其余的元素划分为两个子集。左边子集有 $i$ 个元素，右边子集有 $n-1-i$ 个元素。由于每个子集的组合方式是独立的，所以我们对所有可能的 $i$ 求和，得到总的可能数。

### 二、卡特兰数的显式公式推导

#### 1. **组合数公式的引入**

卡特兰数的递推公式可以通过组合数进行推导。卡特兰数实际上是**二项式系数**的变种，特别是在树形结构、有效括号序列、路径问题等场景中，都可以通过组合数的方式来解释。

卡特兰数的显式公式为：

$$
C_n = \frac{1}{n+1} \binom{2n}{n}
$$

其中，$\binom{2n}{n}$ 是二项式系数，表示从 $2n$ 个元素中选择 $n$ 个元素的组合数。

#### 2. **推导过程**

为了推导显式公式，我们从递推公式出发，尝试找到一个通用的表达式。

首先，将递推公式表示为：

$$
C_n = \sum_{i=0}^{n-1} C_i \times C_{n-1-i}
$$

我们观察到，这个公式实际上描述了将一个问题划分为两个子问题并递归求解的过程。我们可以利用**生成函数**来解决这个递推问题。生成函数是卡特兰数推导的关键工具。

生成函数 $C(x)$ 的定义是：

$$
C(x) = \sum_{n=0}^{\infty} C_n x^n = \frac{1 - \sqrt{1 - 4x}}{2x}
$$

通过分析生成函数，我们可以推导出卡特兰数的显式表达式 $C_n = \frac{1}{n+1} \binom{2n}{n}$。

#### 3. **组合数的解释**

卡特兰数的显式公式可以从组合数的角度进行解释。公式中的 $\binom{2n}{n}$ 表示从 $2n$ 个元素中选择 $n$ 个元素，可能的组合方式数目是 $\frac{(2n)!}{n!n!}$，而前面的 $\frac{1}{n+1}$ 是为了修正一些重复计算的情况，例如在二叉树的结构中，每个二叉树形态存在多次重复。

具体来说，卡特兰数的公式描述了如何从 $2n$ 个节点中选择 $n$ 个节点来形成合法的结构（如有效括号序列、二叉树、路径等），并通过修正因子 $\frac{1}{n+1}$ 来去除多重计数。

### 三、总结

卡特兰数的推导过程从递推公式开始，最终通过生成函数推导出了显式的组合公式。显式公式如下：

$$
C_n = \frac{1}{n+1} \binom{2n}{n}
$$

* **递推公式**是通过将问题分解成子问题，递归计算出每个 $C_n$ 的值。
* **显式公式**则通过组合数的方式给出了计算 $C_n$ 的快速方法，避免了递归计算。

### 四、应用 

> 题目待定

1.  **二叉树的数量**： 给定 `n` 个节点，能够组成的不同二叉树的数量是 $C_n$。这适用于所有可能的二叉树结构，包括二叉搜索树。

2.  **有效括号序列**： 卡特兰数用来计算 `n` 对括号能组成的合法括号序列的数量。每对括号都需要成对匹配，且括号的顺序必须合法。

3. **路径问题（格子路径）： **在一个 $n \times n$ 的网格中，从左下角到右上角的路径数，且每次只能向右或向上走，路径数等于卡特兰数。

4. **堆的数量**  卡特兰数用于计算给定 `n` 个元素时，能够形成的不同堆结构（如最大堆或最小堆）的数量。

5. **递归分治问题** 在某些递归算法中，卡特兰数用于描述递归树的结构。特别是分治法中，子问题的数量和卡特兰数相关。

6. **二叉搜索树的数量** 卡特兰数用于计算 `n` 个节点能够组成的不同二叉搜索树（BST）的数量。每个节点都有一个唯一的值，并且 BST 中左子树的节点值小于父节点，右子树的节点值大于父节点。

7. **表达式的合法性** 卡特兰数可以用于计算具有合法操作符优先级的数学表达式的合法数量。例如，在没有括号的情况下，如何正确地加括号使得表达式合法。
